Three clocks. Explicit denominators.

HTTP call time

The API attempt itself: client, authentication, network, and response. HTTP 200 is transport success, not proof of correct analysis.

Record processing time

First readiness at the queue head to a validated final outcome. Includes admission waiting and retries. Successful-only and all-record averages are separate.

Enqueue-to-completion

From the measured arm's enqueue time to each record's outcome. Includes the backlog ahead of it. This can be much larger than the HTTP time.
