The offline dashboard demonstrates the interface with clearly labeled simulated records. It does not submit inference.

Open the offline demo

git clone https://github.com/patmeh1/azure-llm-batch-starter.git
cd azure-llm-batch-starter
python -m pip install -e ".[dev,cloud]"
llm-batch dashboard --demo

Python 3.11+; Python 3.12 is the tested Functions runtime. Open http://127.0.0.1:8501 locally. For real runs, follow the sign-in, model availability, residency, and cost review in the deployment guide.
